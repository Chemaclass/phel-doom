▤256-color raycaster

DDA ray-march, full viewport, sub-5ms frame→string at 180×40. Half-block sub-cell shading, distance-attenuated palette, RLE-coalesced ANSI emit, sprite z-buffer occlusion. Resize widens FOV, not zoom.

△10 levels, procgen + boss

L1 tutorial imps, L2–L9 procgen mixed floors, L10 hand-authored cyberdemon arena (50 HP boss). Blue / red / yellow keycards, locked doors, and up to 2 hidden secrets per floor.

☠10 enemy types, real AI

Imp, demon, cacodemon, baron, cyberdemon, spectre, revenant, archvile, mancubus, pinky. A dormant → aware → hunting → pain → attacking → wander state machine with BFS noise-wake on every shot and dodgeable telegraphed fireballs.

✵8-weapon arsenal

Pistol, shotgun, chaingun, chainsaw, BFG, incinerator, rocket launcher, super shotgun. DPS-balanced with mag/reserve persistence, auto-spray, a line-piercing pistol, splash AoE, and fire-resist mobs that shrug off the incinerator.

♥Horror beats

Heartbeat vignette + thump on low HP, light flicker, magenta jump-scares, sudden silence, wall haze, ceiling blood drops, blinking door-eyes, and a rear-arc "behind you" warning. Tension, not just sprites.

λPure-functional core

One immutable world map threaded through input → step → cast → render. All side effects fenced into a single IO layer. Math lives in pure modules with 1:1 unit tests.

♺Deterministic replay

Every dice roll runs through one seeded Park-Miller LCG, so seed + input stream fully reproduce a run. --record / --demo capture and replay frame-for-frame; restart re-rolls or repeats the same map on demand.

⌨Terminal-native input

Kitty keyboard protocol for instant key-release (kitty, WezTerm, Ghostty, Alacritty, iTerm2) with a hold-frame fallback for everyone else. Sprint, strafe, about-face, alt-screen redraw with zero scrollback.

♫Synth audio + saves

OS playback via afplay/paplay/aplay/play (bell fallback), distance-scaled SFX, and a synthesized ambient drone. Quick-save to any of 9 slots; high-scores persist best kills, level, and fastest victory.

⚙4 difficulties + perf mode

Easy / normal / hard / nightmare scale enemy speed, HP, count, and respawn. Perf mode auto-engages past 200 columns or 12k cells (30 fps + 2× horizontal scale) so huge terminals stay smooth.
